What can AI Autopilot do?

An autonomous engineer that turns Azure DevOps work items into reviewed pull requests

🔄 End-to-end pipeline

Poll the ADO board → Classify each tagged item (BE / FE / Bug / DB / QC / Requirement) → Route it to the matching Claude Code skill → Execute via the Claude Agent SDK (branch → implement → commit → push) → Auto-review for security → Open a PR → Notify on ADO, Teams, Zalo and email.

Routing
🧭

Title prefixes, work-item type and keywords map each item to a skill command.

Safety
🛡️

Approval gate (draft PRs), RBAC, schedule windows and an automated security review.

Resilience
🔁

Exponential-backoff retries, dry-run mode and full execution history in SQLite.

Observability
📈

Prometheus metrics, structured logs, health checks and token/cost tracking.

Scale
🏢

Multi-repo, multi-tenant, and a Python plugin system for custom pre/post hooks.

Triggers
⚡

Scheduled polling plus an ADO Service Hook webhook for instant pickup.
