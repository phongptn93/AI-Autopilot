{% if ai_native %}

Poll board ADO lấy các item có tag → giao từng item cho agent (Claude chạy từ workspace với toàn bộ skill bên dưới) → agent suy luận, lập kế hoạch, chọn skill phù hợp, implement, tự review và mở PR → trả về kết quả có cấu trúc → control plane theo dõi, gắn tag và thông báo, hoặc chuyển cho người.
