Giải xung đột kiểm tra gì trước khi push
  1. Không còn marker <<<<<<< / ======= / >>>>>>> trong file xung đột, và git không báo path nào chưa merge.
  2. Không sửa file nào ngoài các file xung đột.
  3. Không có lỗi bảo mật mới mà cả hai phía merge đều chưa có.
  4. Test của repo pass (khi bật cổng test).
  5. Push không dùng --force — nếu branch đã đổi trong lúc đó thì dừng, không ghi đè.
