⚔️ PR conflicts

Pull requests ADO cannot merge because their branch conflicts with the target. A conflicted PR is not "ready to merge" however it was voted — it leads the delivery report instead. Resolution merges the target into the PR branch (never a rebase, never a force-push, so reviewed commits and comments stay put) and pushes only after objective checks pass; otherwise the merge is aborted and the branch is left exactly as it was.

What a resolution checks before it pushes
  1. No <<<<<<< / ======= / >>>>>>> marker left in any conflicted file, and git reports no unmerged path.
  2. Nothing outside the conflicted files was edited.
  3. No security finding that neither side of the merge had.
  4. The repo's tests pass (when the test gate is on).
  5. Push without --force — if the branch moved meanwhile, it stops instead of overwriting.
