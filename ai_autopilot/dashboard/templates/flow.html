🔀 State flow per work-item type

An ADO state belongs to a type — Ready to Deploy exists on Bug and Task but not on Requirement — so one project-wide state per stage is rejected outright for every type that doesn't define it. Group the types that share a lifecycle and give each group its own states. Anything this project can't accept is refused here rather than failing later, one work item at a time.
