⏰ Scheduled agents

Agents that run on a clock instead of on a work item. A report loop inspects and writes findings — read-only, no branch, no PR — and lands on Reports. A PR loop changes files and opens a pull request, and is judged by that diff. Pick the sub-agents each loop delegates to; they come from your workspace's .claude/agents.
