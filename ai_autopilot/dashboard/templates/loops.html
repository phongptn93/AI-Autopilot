Agent chạy theo lịch thay vì theo work item. Loop report chỉ đọc và ghi kết quả vào Báo cáo; loop pr sửa code và mở pull request.

Chi tiết

Loop report không tạo branch, không mở PR — chỉ lưu những gì nó tìm thấy. Loop scan chạy các công cụ quét bảo mật (có thể kèm AI) và đổ kết quả vào Bảo mật. Loop pr sửa file, mở pull request và được đánh giá qua chính diff đó.

Mỗi loop có thể giao việc cho các sub-agent trong .claude/agents của workspace. Lưu vào scheduled_loops, lịch được cập nhật ngay.
