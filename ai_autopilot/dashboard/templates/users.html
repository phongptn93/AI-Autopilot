  • Cho dashboard tự chạy HTTPS: điền Chứng chỉ HTTPS và Khoá riêng HTTPS (file .pem) ở Thiết lập → 👥 Người dùng & SSO, rồi khởi động lại.
  • Đặt sau reverse proxy (IIS, Caddy, nginx…) đã có HTTPS, rồi điền Địa chỉ public của dashboard (vd https://autopilot.congty.vn) ở cùng chỗ đó.

  1. Tạo ứng dụng

    Entra admin center → App registrations → New registration. Tên AI Autopilot, loại tài khoản Accounts in this organizational directory only.

  2. Redirect URI loại Web

    Dán đúng địa chỉ này vào ô Redirect URI:

  3. Tạo client secret

    Certificates & secrets → New client secret → copy cột Value (chỉ hiện một lần).

  4. Gán vai tự động tuỳ chọn

    App roles: tạo AIAutopilot.Admin, AIAutopilot.BA… rồi gán người/nhóm ở Enterprise applications. Hoặc bật groups claim ở Token configuration.

  5. Điền vào AI Autopilot

    Lấy Directory (tenant) ID và Application (client) ID ở trang Overview của app, điền cùng client secret ở Thiết lập → 👥 Người dùng & SSO. Bấm Thử kết nối bên dưới, rồi bật SSO công ty ở đầu trang.
