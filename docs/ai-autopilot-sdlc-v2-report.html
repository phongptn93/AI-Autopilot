3 · Cách sử dụng khác biệt

① Bật per-máy (knob chính)

Mỗi người 1 máy, mỗi máy 1 vai trò — cấu hình trong config.yaml của máy đó:

sdlc_loop_enabled: true
sdlc_profile: dev        # máy này chỉ chạy Dev
sdlc_max_iterations: 3

② Ghi đè theo item (tuỳ chọn)

Gắn tag sdlc:<profile> lên work item để ép 1 luồng riêng, thắng cấu hình máy:

gắn tag  sdlc:ba   → chỉ chạy giai đoạn BA
gắn tag  sdlc:qc   → chỉ chạy giai đoạn QC

4 · Khác nhau so với ban đầu

BAN ĐẦU one-shot

tag → 1 Claude run→ PR→ score 1 lần→ DỪNG
  • 1 lần chạy = 1 chuỗi skill mờ = 1 PR
  • Không có stage rõ ràng, không gate từng bước
  • Không tự lặp lại khi review/CI fail
  • Không chia vai trò theo máy

SAU closed-loop

profile→ stage → gate↺ revise (budget)→ handoff máy kế
  • Chuỗi stage tường minh, chọn theo profile/máy/tag
  • Gate mỗi stage, revise theo budget chung, escalate khi hết
  • Resumable: crash giữa loop → chạy tiếp đúng chỗ
  • Chia BA/Dev/QC theo máy, bàn giao qua state

Đơn vị chạy1 run / itemN stage / item, có state machine
Chọn phạm viluôn full (model tự quyết)profile chỉ định (ba/dev/qc/full/custom)
Khi lỗiretry lại từ đầurevise đúng stage, budget chung, rồi escalate
Đa máy / teamkhôngrole-per-machine + handoff qua ADO state
